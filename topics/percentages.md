# Percentages

## 1. Core Concept & Fundamental Equations

- $x\%=x/100$. Percentage change $=\frac{\text{change}}{\text{original}}\times100\%$.
- New value after increase/decrease of $r\%$: $V(1\pm r/100)$.
- Successive changes $a\%$ and $b\%$ give net change $a+b+ab/100$; use negative values for decreases.
- If $A$ is $p\%$ more than $B$, then $B$ is $\frac{p}{100+p}\times100\%$ less than $A$.
- If $A$ is $p\%$ less than $B$, then $B$ is $\frac{p}{100-p}\times100\%$ more than $A$.
- Common conversions: $1/2=50\%$, $1/3=33\frac13\%$, $1/4=25\%$, $1/5=20\%$, $1/8=12.5\%$, $1/10=10\%$.

## 2. Universal Shortcut Engine

| Technique | Use it when | Avoid it when |
|---|---|---|
| Base $100$ | Comparing percentage changes or choosing a convenient assumed total. | An actual base is supplied and easy to use. |
| Fraction conversion | Percentages are familiar fractions such as $12.5\%$ or $33\frac13\%$. | The fraction creates awkward arithmetic. |
| Successive multiplier | Several increases/decreases are applied in sequence. | Changes refer to different bases; identify each base first. |
| Reverse percentage | Final value and change rate are known. | The change is additive or uses a different reference quantity. |
| Option elimination | Options differ clearly by scale or sign. | Close options require exact computation. |

## 3. Model-Wise Question Classification

### Model 1: Find a percentage of a quantity
**Problem:** Find $35\%$ of $240$.
- **Method A:** $0.35\times240=84$.
- **Method B:** $35\% = 7/20$; $240/20\times7=84$. **Answer: $84$.**

### Model 2: Successive increase and decrease
**Problem:** A value rises by $20\%$ and then falls by $10\%$. Find the net change.
- **Method A:** Start at $100$: $100\to120\to108$, a net increase of $8\%$.
- **Method B:** $20+(-10)+(20\times-10)/100=8\%$. **Answer: $8\%$ increase.**

### Model 3: Reverse percentage
**Problem:** After a $20\%$ discount, a price is $800$. Find the original price.
- **Method A:** $80\%$ of original is $800$, so original $=800/0.8=1000$.
- **Method B:** Discounted price is $4/5$ of original; $800\times5/4=1000$. **Answer: $1000$.**

### Model 4: Population growth
**Problem:** A town of $20,000$ grows by $10\%$ per year. Find its population after two years.
- **Method A:** Year 1: $22,000$; year 2: $24,200$.
- **Method B:** $20,000(1.1)^2=24,200$. **Answer: $24,200$.**

### Model 5: Marks and pass percentage
**Problem:** A candidate scores $360$ out of $450$. Find the percentage.
- **Method A:** $(360/450)\times100=80\%$.
- **Method B:** Simplify $360/450=4/5$; $4/5=80\%$. **Answer: $80\%$.**

## 4. Exam-Specific Alignment & Variations

- **SSC lens:** Successive changes, comparison reversals, marks, expenditure, and population questions.
- **RRB lens:** Direct percent-of-quantity calculations and changes embedded in word problems.
- **AP State / PSU lens:** Percentage blended with profit-loss, data interpretation, salary, production, and election results.

## 5. Common Traps & Speed Killers

1. **Wrong base after a change:** each successive percentage applies to the current value.
2. **Treating a decrease and increase as cancellation:** $+20\%$ then $-20\%$ is a $4\%$ net decrease.
3. **Reversing comparison percentages:** “A is 25% more than B” does not mean B is 25% less than A; use the original base.
